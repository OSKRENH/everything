# Кутно

«Кутно» подбирает три рецепта из продуктов и кухонного инвентаря, которые уже есть дома.

## Локальный запуск

```bash
npm install
npm run dev
```

В режиме локального Vite-превью интерфейс автоматически использует встроенную подборку, если Workers AI недоступен. В Cloudflare запросы `/api/*` обрабатывает Worker, остальные маршруты обслуживаются как SPA.

## Проверка и публикация

```bash
npm run check
npm run deploy
```
